# 果冻大逃亡

一款使用纯 HTML、CSS 和 Canvas 2D API 制作的双人迷宫动作游戏。

## 运行方式

直接打开 `index.html` 即可本地游玩。

## 发布到 GitHub Pages

本项目是纯静态网页，适合直接部署到 GitHub Pages。

1. 创建 GitHub 仓库。
2. 推送本项目到仓库。
3. 在仓库 `Settings -> Pages` 中选择 `Deploy from a branch`。
4. 分支选择 `main`，目录选择 `/root`。
5. 保存后等待 GitHub 生成网页链接。

## 操作

- P1：WASD 移动，J 攻击，左 Shift 冲刺。
- P2：方向键移动，Enter 攻击，右 Shift 冲刺。

## 规则

- 合作模式：两名玩家各自吃完同色水果，大门才会开启；两人都进入大门才通关。
- PK 模式：谁先吃完自己的水果并进入大门，谁获得胜利。
- 被敌人抓到后，合作模式可由队友靠近救援；PK 模式会回出生点并短暂眩晕。
- 道具包含冰冻敌人、护盾、磁吸水果和加速。
- 每个主题关卡都有不同机关：加速垫、冰面、流沙。
